AI Job Readiness Bootcamp — User Stories

Week 1 — Foundations & Setup

Goal: Set up environment, run first AI experiments.

As a learner, I want to set up Python, VSCode/Jupyter, and Git, so that I have a proper environment for AI experiments.

As a beginner, I want to practice basic Python scripts, so that I can manipulate data and run experiments confidently.

As a user, I want to experiment with AI APIs (OpenAI, Hugging Face, Stability AI), so that I understand how to get outputs from pre-trained models.

As a learner, I want to summarize a document using GPT, so that I understand text processing with AI.

As a user, I want to generate an image from a text prompt, so that I can explore AI-generated content.

As a learner, I want to combine text and image generation, so that I can create multi-modal outputs.

As a developer, I want to document all experiments in a README, so that my progress is organized and reproducible.

Week 2 — Project 1: AI Summarizer / Research Assistant

Goal: Build the first deployable AI product.

As a researcher, I want to upload multiple PDFs, so that I can get concise summaries automatically.

As a developer, I want to clean and process documents, so that AI can work effectively on them.

As a user, I want GPT to summarize documents, so that I can quickly extract key insights.

As a user, I want a web interface to upload documents and view summaries, so that it’s easy to interact with the tool.

As a user, I want to download summaries and save history, so that I can maintain a record of insights.

As a developer, I want a polished UI and clear disclaimer, so that the app is professional and safe to use.

As a user, I want to access the deployed app online, so that it’s available anywhere.

Week 3 — Project 2: AI Chatbot / Knowledge Base

Goal: Build a chatbot using embeddings + GPT.

As a user, I want to ask questions about documents, so that I can get instant answers.

As a developer, I want to convert documents into embeddings, so that GPT can retrieve relevant context.

As a developer, I want a function to retrieve top embeddings and generate answers, so that responses are accurate.

As a user, I want a simple web interface to chat with the AI, so that it’s easy to use.

As a user, I want conversation memory, so that I can have multi-turn interactions.

As a tester, I want to validate answers with sample queries, so that the chatbot provides correct and relevant information.

As a developer, I want to deploy the chatbot with documentation, so that it’s accessible and reproducible.

Week 4 — Project 3: AI Workflow / Automation

Goal: Build multi-step AI workflows combining APIs.

As a user, I want to scrape or ingest new data automatically, so that I don’t need to do it manually.

As a developer, I want to process data through AI models, so that summaries or outputs are generated automatically.

As a user, I want to receive automated reports (text, images, or combined), so that I save time.

As a developer, I want to schedule workflows or trigger them on demand, so that the process runs reliably.

As a user, I want an interactive dashboard to monitor the workflow, so that I can check results anytime.

As a developer, I want multi-step orchestration combining text, image, and other outputs, so that complex tasks are automated.

As a tester, I want to ensure error handling and stability, so that the workflow is robust.

As a developer, I want to prepare portfolio-ready demos with README, screenshots, and live links, so that my work is presentable professionally.

As a learner, I want to document reflections and post mini demo videos, so that I can showcase my skills publicly.
